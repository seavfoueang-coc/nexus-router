  3. Send your first requestReplace YOUR_API_KEY and the model with your own.

Authentication

Send your key with every request. Either header works on every endpoint:

HeaderExampleUsed by
AuthorizationAuthorization: Bearer sk-…OpenAI SDKs, most apps
x-api-keyx-api-key: sk-…Anthropic (Claude) SDKs

Do not put your key in a website or mobile app that other people download. Anyone can read it from there. Call the API from your own server or computer instead.

Chat completions

POST /v1/chat/completions accepts the standard OpenAI body: model, messages, and optional max_tokens, temperature, stream, tools.

Response
{
  "id": "chatcmpl-1793610548953",
  "object": "chat.completion",
  "model": "claude-opus-5.5",
  "choices": [{
    "index": 0,
    "finish_reason": "stop",
    "message": { "role": "assistant", "content": "Hi. What are you working on?" }
  }],
  "usage": { "prompt_tokens": 379, "completion_tokens": 9, "total_tokens": 388 }
}

Claude messages

POST /v1/messages takes Anthropic's format, so the official Claude SDKs and tools work without changes. max_tokens is required in this format.

cURL
curl {{ORIGIN}}/v1/messages \
  -H "x-api-key: YOUR_API_KEY" \
  -H "anthropic-version: 2023-06-01" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "{{MODEL}}",
    "max_tokens": 1024,
    "messages": [{"role": "user", "content": "Hello!"}]
  }'

Responses

POST /v1/responses follows OpenAI's Responses API, used by newer OpenAI SDK features and some agents.

cURL
curl {{BASE}}/responses \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model": "{{MODEL}}", "input": "Hello!"}'

Streaming

Add "stream": true to get the answer piece by piece as it is written. The response uses Server-Sent Events: lines starting with data:, ending with data: [DONE].

stream = client.chat.completions.create(
    model="{{MODEL}}",
    messages=[{"role": "user", "content": "Write a short poem."}],
    stream=True,
)
for chunk in stream:
    print(chunk.choices[0].delta.content or "", end="", flush=True)
const stream = await client.chat.completions.create({
  model: "{{MODEL}}",
  messages: [{ role: "user", content: "Write a short poem." }],
  stream: true,
});
for await (const chunk of stream) {
  process.stdout.write(chunk.choices[0]?.delta?.content ?? "");
}
curl -N {{BASE}}/chat/completions \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model": "{{MODEL}}", "stream": true,
       "messages": [{"role": "user", "content": "Write a short poem."}]}'

Models

Each key can only use the models the owner allowed for it. To see yours, open the balance page or call GET /v1/models:

cURL
curl {{BASE}}/models -H "Authorization: Bearer YOUR_API_KEY"

Use the model ID exactly as listed, for example {{MODEL}}. Asking for any other model returns 403 Model … is not allowed for this API key.

Tool calling

Describe functions in tools. When the model wants one, the reply has finish_reason: "tool_calls"; run the function and send the result back as a tool message.

Python
tools = [{
    "type": "function",
    "function": {
        "name": "get_weather",
        "description": "Get the current weather for a city",
        "parameters": {
            "type": "object",
            "properties": {"city": {"type": "string"}},
            "required": ["city"],
        },
    },
}]

reply = client.chat.completions.create(
    model="{{MODEL}}",
    messages=[{"role": "user", "content": "Weather in Bangkok?"}],
    tools=tools,
)
print(reply.choices[0].message.tool_calls)

Keep the key out of your code

Store the key in an environment variable and read it at run time:

setx OPENAI_BASE_URL "{{BASE}}"
setx OPENAI_API_KEY "YOUR_API_KEY"
:: open a new terminal afterwards
export OPENAI_BASE_URL="{{BASE}}"
export OPENAI_API_KEY="YOUR_API_KEY"
# add these lines to ~/.zshrc or ~/.bashrc to keep them

The OpenAI SDKs read OPENAI_BASE_URL and OPENAI_API_KEY automatically, so OpenAI() then needs no arguments.

Tokens and limits

A token is a small piece of text, roughly ¾ of an English word. Your key has a token limit set by the owner.

  • What counts: input tokens (everything you send, including earlier messages and system prompts) plus output tokens (the answer).
  • Every request has extra input. Even "Hello" costs a few hundred input tokens, because instructions are added to each request.
  • Exact usage is in every response under usage, and on the balance page.

One-time balance

A fixed number of tokens that never resets. When it is used up, the key stops working until the owner adds more.

Daily, weekly or monthly

The count starts over each period, at 00:00 UTC. Weekly limits reset on Monday; monthly ones on the 1st.

A key can also have an expiry date, after which it stops working. Both are shown on the balance page.

When you run out

Requests are refused with 429 and "code": "token_limit_exceeded":

Response
{
  "error": {
    "message": "Out of tokens. This API key has used its full one-time 50M token limit. This limit does not reset.",
    "type": "rate_limit_error",
    "code": "token_limit_exceeded"
  }
}

A request that is already running finishes normally, so the last request can go slightly over the limit.

Errors

Errors come back as JSON with an error.message that explains the problem.

StatusMeaningWhat to do
400The request body is invalid.Check the JSON and required fields such as model and messages.
401No key was sent, the key is wrong, or the key was turned off.Check the header and the key. If it still fails, ask the owner.
403The model is not allowed for your key, or the key has expired.Use a model from your balance page, or ask the owner to extend the key.
429Out of tokens (token_limit_exceeded), or too many requests at once.Wait for the reset shown on your balance page, or ask for more tokens.
502 503The service or the AI provider is temporarily unavailable.Wait a moment and try again.

FAQ

Which base URL do I use, with or without /v1?
OpenAI SDKs and most apps: . Anthropic (Claude) SDKs and Claude Code: , because they add /v1 themselves.
How do I see how many tokens I have left?
Open the balance page and paste your key. It shows tokens left, input and output used, when it resets, and when the key expires.
Why did a short message use hundreds of tokens?
Each request includes instructions and, in chats, all earlier messages. These count as input tokens. Starting a new conversation keeps requests smaller.
Can I use another model?
Only the models allowed for your key work. Ask the owner if you need a different one.
My key stopped working. Why?
It ran out of tokens, expired, or was turned off by the owner. The balance page shows which one.
I think my key leaked. What should I do?
Tell the owner right away so they can turn it off and give you a new one. Anyone with your key can use your tokens.
